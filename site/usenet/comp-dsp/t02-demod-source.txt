OK, it IS BPSK. Symbol period 0.5634 s (1.775 baud), differential, and
the bitstream frames cleanly into 8-N-1 ASCII. Side A gives 284 bytes.
Core loop below. Runs on a stock Mac Plus at about 4x real time.

/* stardust.c -- coherent 14.2 Hz DBPSK demod. Public domain. */
#define FC   14.2
#define FS   64.0
#define SPS  36          /* samples per symbol (64 * 0.5634) */

    for (n = 0; n < len; n++) {
        i_acc += x[n] * cos(2*PI*FC*n/FS);
        q_acc += x[n] * sin(2*PI*FC*n/FS);
        if (++k == SPS) {
            ph  = atan2(q_acc, i_acc);
            bit = fabs(ph - last_ph) > PI/2;
            emit(bit); last_ph = ph; i_acc = q_acc = 0; k = 0;
        }
    }

First decoded lines of side A, US pressing:

    STARDUST/1 KESTREL NODE 01 OF 14 -- HOLD FOR RELAY
    NOVA HART TO ALL STATIONS

I have no idea what that means. Anyone?
